# تخطيط لوحة المفاتيح Arabic Custom 102

**اللغات:** 🇸🇦 العربية | [🇺🇸 English](README.md)

---

يوفر هذا المشروع تخطيط XKB مطابقًا قدر الإمكان لتخطيط **Microsoft Windows Arabic (102)** على أنظمة Linux المعتمدة على Debian، مع المحافظة على التوافق الكامل مع نظام XKB القياسي.

الهدف من المشروع هو تمكين مستخدمي Windows من الانتقال إلى Linux دون الحاجة إلى إعادة تعلم أماكن المفاتيح.

---

## لماذا هذا المشروع؟

لا توفر العديد من توزيعات لينكس تخطيط لوحة مفاتيح مطابقًا تمامًا لتخطيط لوحة مفاتيح مايكروسوفت ويندوز العربية (102).

بالنسبة للمستخدمين الذين أمضوا سنوات في الكتابة على ويندوز، غالبًا ما يعني الانتقال إلى لينكس إعادة تعلم مواضع المفاتيح واختصارات لوحة المفاتيح.

يهدف هذا المشروع إلى توفير تجربة كتابة مألوفة من خلال محاكاة تخطيط لوحة مفاتيح ويندوز العربية (102) بأكبر قدر ممكن من الدقة، مع الحفاظ على التوافق التام مع بنية XKB القياسية.

---

## المميزات

- مطابق تقريبًا لتخطيط Windows Arabic (102)
- مفتاح **ذ** بجانب Enter
- يدعم:
  - Alt + Shift الأيسر
  - Alt + Shift الأيمن
- المحافظة على جميع وظائف AltGr
- يعتمد على XKB القياسي
- تثبيت على مستوى النظام
- حزمة Debian جاهزة (.deb)
- يدعم التثبيت والترقية والإزالة بشكل صحيح
- مفتوح المصدر

---

## الأنظمة المدعومة

تم اختباره على:

- Linux Mint 22.3 XFCE

ومن المتوقع أن يعمل على معظم توزيعات Debian وUbuntu التي تستخدم XKB.

---

## التثبيت

قم بتنزيل أحدث إصدار من صفحة Releases.

ثم ثبّت الحزمة:

```bash
sudo dpkg -i arabic-custom-102-xkb_1.0.0 .deb
```

بعد التثبيت:

- سجّل الخروج ثم الدخول مرة أخرى.

ثم افتح:

الإعدادات → لوحة المفاتيح → التخطيطات

واختر:

```
Arabic (102) - Windows Layout
```

---

## إزالة التخطيط

```bash
sudo apt purge arabic-custom-102-xkb
```

---

## الترقية

يكفي تثبيت الإصدار الجديد فوق الإصدار القديم:

```bash
sudo dpkg -i arabic-custom-102-xkb_<version> .deb
```

ولا حاجة لإزالة الإصدار السابق.
